# Mahmoud & Sara — Engagement Invitation

A responsive, static engagement invitation with a gated cover page and an elegant dark charcoal-and-gold theme.

## Features
- Guests must press **Open Invitation** before the rest of the invitation is revealed.
- Music starts when the guest presses the opening button (browser audio rules may still vary by device).
- Countdown to Friday, 23 October 2026 at 5:00 PM Cairo time.
- Venue map link, RSVP and wishes via WhatsApp.
- Invitation poster image displayed on the second section.

## Files
Keep these files together in the root of your GitHub repository:
- `index.html`
- `styles.css`
- `script.js`
- `config.js`
- `music.mp3`
- `invitation-poster.png`

## Publish or update on Vercel
Upload the files above to your GitHub repository, replacing the earlier versions, and commit the changes. Vercel should redeploy automatically if the GitHub repository is already connected.

## Notes
- Music is attempted at the click of **Open Invitation**, which is usually accepted as a user gesture. Device/browser settings may still affect playback.
- RSVP and wishes open WhatsApp with a prefilled message; they are not stored in a database.
- Replace the WhatsApp number, date or venue in `config.js` if details change.
